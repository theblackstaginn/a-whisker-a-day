# Hearth artwork — development source assets

Generated with the built-in image tool from `../yarrow-storybook.webp`.
The apothecary plate was then supplied alongside that original reference when generating the anatomy atlas, locking the shared style and lighting.

`apothecary.webp`: 1024×1536 opaque background, 774122 bytes.
`yarrow-parts.webp`: 1536×1024 RGBA anatomy atlas, 430980 bytes.

Art brief: warm fine-ink storybook gouache, earthy parchment, moss and sage, honey light and brass; apothecary shelves and herbs framing a central sage cushion. Yarrow is solid velvety BLACK with amber eyes, sage ribbon and brass crescent. No tabby, calico, white patches, lettering or photographic treatment. Separate head, ears, torso, two front legs and tail with fur-covered roots; no attached room scenery.

WebP export: quality 92 and alpha quality 100. Original Yarrow reference is unchanged. These are reusable painted sources, not completed animation frames. Atlas crop coordinates and pivots are defined in `yarrow-cutout.js` and `yarrow-cutout.css`; motion needs browser verification before release.
